# RawDeveloper

Windows 用の RAW 現像ソフト。C++20 ＋ Qt 6 ＋ LibRaw。

- `src/engine/` … 現像エンジン（画面に依存しない部分）
- `src/ui/` … 画面（Qt 6 Widgets）
- `tests/` … エンジンの動作確認
- `prototype/python/` … Python 版の初期版（機能の仕様・見た目の基準）

## exe の入手
GitHub の「Actions」タブ → 最新の「Build Windows」→ 下の「Artifacts」から `RawDeveloper-windows` をダウンロードして展開し、`RawDeveloper.exe` を起動します。

## 開発状況
C++ 版は移植中です。

- できること：フォルダの写真をフィルムストリップで切り替え、基本補正・自動調整・カラーホイール・トーンカーブ・HSL・ディテール・切り抜きと角度、
  パネルごとのオン/オフ（Alt＋クリックでソロ）と初期値に戻す、比較表示（ワイプ左右/上下、並べて左右/上下/自動、履歴の任意時点と比較）、
  スコープ（ヒストグラム・波形・パレード・ベクトル）、履歴（元に戻す/やり直す）、.rdev 保存（Python 版と共通）、JPEG 書き出し、
  レンズ補正（Lensfun：自動判別・手動選択・歪曲・周辺減光・色収差、手動補正）、拡大中の部分高精細表示
- ライブラリ（G）：フォルダツリー、サムネイル一覧（Ctrl＋ホイールで大きさ）、★・ラベル・採用/除外、絞り込み・並べ替え、撮影情報
  - キー：0〜5 ★／[ ] ★増減／6〜9 ラベル（赤黄緑青）／P 採用・X 除外・U なし／D・Enter 現像／F 全画面で選別
  - 保存先：RAW は .rdev（設定で .xmp も）、JPEG・TIFF・PNG はファイル自体の XMP（エクスプローラーの★にも出ます）
- 書き出し（Ctrl＋Shift＋E）：JPEG／TIFF 16bit／PNG、選択・表示中すべて・★N 以上・採用だけ、長辺指定、ファイル名テンプレート、
  プリセット、★・ラベル埋め込み。書き出したファイルは元の写真と紐付き、元の★を変えると反映できます（環境設定）
- 切り抜き中：← → で角度 0.1°（Shift 1°・Ctrl 0.01°）。黒い余白が出ないよう枠が自動で縮みます
- 自動調整：シーン判別（逆光・明るい背景・夜景・夕景・電球色、カメラの露出補正）＋縮小画像で仕上がりを評価しながら値を探索。
  WB は自然な光の範囲で、夕景・電球の雰囲気を残します
- 調整のコピー：Ctrl＋C／Ctrl＋Shift＋C（項目を選ぶ）／Ctrl＋V（選択中すべてに）／Ctrl＋Alt＋V（前の写真と同じ）、
  露出を写真ごとの明るさに合わせる、まとめて自動調整（Ctrl＋Shift＋U）、同期モード、貼り付け直後は「元に戻す」
- ノイズ軽減（Lightroom 風）：輝度（適用量・ディテール・コントラスト）／カラー（適用量・ディテール・滑らかさ）。
  ウェーブレットで細かさ別に、画像から測ったノイズ量に合わせて処理。輝度の初期値は ISO から自動
- 肌色：いい感じに（弱め・普通・強め）、肌をクリックして指定、色相・彩度・明るさ、均一化（色相・彩度・明るさ）、範囲と表示
- これから：GPU 化、AI ノイズ除去、肌のなめらかさ、マスク・部分補正

## 手元でビルドする場合
Visual Studio 2022、CMake、vcpkg、Qt 6 を入れて：

```
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=<vcpkg>/scripts/buildsystems/vcpkg.cmake -DCMAKE_PREFIX_PATH=<Qt>/msvc2022_64
cmake --build build --config Release
```
