# RawDeveloper（初期版・Python 試作）

Windows 用の RAW 現像ソフトです。元の RAW は書き換えず、調整内容を `写真名.rdev` に保存します（非破壊編集）。

## はじめかた

1. Python 3.11 または 3.12 を入れる（https://www.python.org/ ・インストール時に「Add python.exe to PATH」にチェック）
2. このフォルダの `setup.bat` をダブルクリック（初回だけ。数分かかります）
3. `run.bat` をダブルクリックで起動
   - うまく起動しないときは `run_debug.bat` を使うと、エラーの内容が表示されます

| トーンカーブ | Y・R・G・B の点カーブ（後ろにヒストグラム表示） |
| カラー | HSL（8 色の色相・彩度・輝度）、カラーホイール（リフト・ガンマ・ゲイン・オフセット） |

### DaVinci Resolve 風の操作
- 数値の上を左右ドラッグで増減（Ctrl：微調整／Shift：粗調整）。画面の端まで来ても反対側から続けて動かせます
- ダブルクリックで初期値に戻す、クリックで数値入力（`+=0.3` で今の値に足す）
- `Shift+D` で補正のオン／オフ、`Y` でワイプ比較（線をドラッグ）
- フィルムストリップの写真を中クリックすると、その写真の調整を今の写真にコピー
- ヒストグラムの区画（黒レベル〜白レベル）を左右ドラッグすると、対応するスライダーが動きます。スライダーにマウスを乗せると区画が光ります
- ヒストグラムをなぞると、写真の中のその明るさの部分が色付きで表示されます

### 現像後のファイルへのレーティング
- 書き出し時に ★・ラベルをファイルに埋め込みます（JPEG は XMP と EXIF、TIFF・PNG は XMP）
- ライブラリで JPEG・TIFF・PNG にも直接 ★・ラベルを付けられます。画像は再圧縮せず、情報部分だけを書き換えます
- 書き出したファイルは元の RAW と紐付き、あとで RAW の ★ を変えると「書き出したファイルにも反映しますか？」と聞きます（環境設定で「常に／しない」に変更可）
- Windows のエクスプローラーで見えるのは ★ だけです。ラベルは Lightroom・Bridge などで読めます

## 保存場所
- 調整内容・★・ラベル：写真と同じフォルダの `写真名.rdev`（JSON）
- カタログ・プリセット：`%APPDATA%\RawDeveloper\`
- サムネイルのキャッシュ：`%LOCALAPPDATA%\RawDeveloper\thumbs\`
- 環境設定で「RAW の★・ラベルを XMP サイドカーにも書く」をオンにすると、`写真名.xmp` も作ります（Lightroom などと共有用）

## この試作の制限
- 処理は Python（NumPy・OpenCV）です。スライダー操作中は長辺 1600px のプレビューで計算し、ズームすると数秒後に高精細表示に切り替わります。24MP の書き出しは 1 枚 10 秒前後かかります
- ハイライト・シャドウは画面全体に一様に効きます（局所的な処理は本格版で）
- 色温度の数値は、Lightroom など他のソフトと同じにはなりません
- RAW に内蔵されたメーカー純正の補正データ（優先順位 1 番目）は、LibRaw が取り出せないため未対応です。Lensfun に無いレンズは「手動」タブで補正できます
- 書き出しの色空間は sRGB のみです。モニターのカラープロファイルには未対応です
- 次版以降の予定：テクスチャ・明瞭度・かすみ除去、カラーグレーディング、部分補正、スポット修正、比較表示、スマートコレクション、GPU 化

## 単体の exe にしたいとき
`build_exe.bat` を実行すると `dist\RawDeveloper\RawDeveloper.exe` ができます（PyInstaller 使用）。
